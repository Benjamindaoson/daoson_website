HOW I WORK

问题 → 实验 / 系统 → 证据Problem → experiment / system → evidence

01

定义可证伪的问题Define a falsifiable question

先把假设、任务约束、失败模式或真实业务场景写清楚。Start by making the hypothesis, task constraints, failure modes, or operating context explicit.

02

构建可检查的工件Build inspectable artifacts

训练、评估、运行轨迹、契约与代码都应该支持结论，而不是只留下截图。Training, evaluation, runtime traces, contracts, and code should support the claim rather than leaving only screenshots.

03

明确能力边界Keep capability boundaries explicit

研究结果、系统原型、学习材料和生产级能力不混为一谈。Research results, system prototypes, learning material, and production-grade capability remain distinct.
